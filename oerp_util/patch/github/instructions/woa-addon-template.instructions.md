# WOA Addon Template for New Modules

For **new Odoo modules**, use the template at **`.cursor/templates/woa_addon`**.

- When creating a new module, adopt the files and directory structure from the template.
- Copy both icons: `static/description/icon.svg` **and** `static/description/icon.png`.
- Adjust the module name, `name`/`summary` in the manifest, and dependencies as needed; set the version to `19.0.x.y.z`.
- Also observe the project conventions (OCA Coding Style, readme documentation under `readme/`).
