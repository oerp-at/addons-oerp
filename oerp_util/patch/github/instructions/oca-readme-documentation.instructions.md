# OCA Readme Documentation

New features and modules are documented in the **`readme/`** folder, as specified by the **OCA structure**.

## Directory Structure

Per module, a subfolder `readme/` with optional Markdown files:

- **DESCRIPTION.md** – What the module does, target audience, typical use cases (update/extend for new modules or new features).
- **USAGE.md** – Usage, workflow, examples.
- **CONFIGURE.md** – Configuration (settings, options).
- **INSTALL.md** – Installation notes, if needed.
- **CONTRIBUTORS.md** – Contributors.
- **ROADMAP.md**, **CREDITS.md** – optional.

## For New Features

- Update **DESCRIPTION.md** when the module's purpose or scope changes.
- Extend **USAGE.md** when new workflows or usage scenarios are added.
- Supplement **CONFIGURE.md** when new settings/options are introduced.

Filenames lowercase and underscores only; format Markdown (`.md`). Keep it concise and clear.
